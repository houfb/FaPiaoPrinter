# FaPiaoPrinter 发票合并打印工具

## 用途说明：
一个用于将多张PDF版发票合并到一个PDF页面上去打印的工具，它主要是帮助节约纸张，对比WPS等Office软件中自带的那个，优点是无任何依赖、完全彻底免费。

## 使用方法：
1. 从github仓库的发布文件中下载 FaPiaoPrinter.exe ，放到本地的任意一个目录中，当然，放桌面也没啥问题。
2. 双击这个exe文件，出现一个黑窗口，提示【请输入发票PDF文件的路径(可以一个一个地拖进来)或目录，输入完成后直接回车：】。
3. 按提示手动一个个地输入你要合并的发票PDF文件，多个文件中间可以加个空格区分一下，或者，你直接鼠标选中你要合并的多个PDF文件，拖到黑窗口中，然后按下键盘上的 Enter 键。
4. 电脑桌面上就会出现一个【合并后.pdf】，这就是合并结果，若你电脑上按装了金山WPS、微软Office、永中Office这类办公软件，这个合并后的PDF文件会被自动打开，你直接去点击其打印按钮去打印就行了。
